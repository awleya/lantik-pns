Alur Kerja Sistem

Panduan Penggunaan Terpadu Dashboard LANTIK-PNS

LANTIK-PNS mempermudah pemantauan kenaikan pangkat secara terbuka untuk Pegawai/Masyarakat, serta menyediakan portal verifikasi khusus untuk Verifikator BKPSDM Kabupaten Lima Puluh Kota.

1. Untuk Pengguna Umum / Pegawai
  • Pencarian Cepat: Masukkan 18 digit NIP atau Nama pada kotak pencarian di atas tabel utama untuk menemukan status usulan Anda secara presisi.
  • Penyaringan Data: Gunakan panel filter di bagian atas untuk menyaring usulan berdasarkan Periode KP, Unit Kerja (OPD), Status Akhir, Jenis KP, dan Verifikator.
  • Export Data Excel: Klik tombol Export Excel pada bilah navigasi untuk mengunduh rekapitulasi data usulan yang terfilter.
  • Monitoring Visual & KPI: Pantau ringkasan statistik usulan melalui kartu KPI dan grafik interaktif (Status per OPD, Tahapan, Jenis KP, dan Beban Verifikator).
2. Untuk Verifikator (BKPSDM)
  • Otorisasi / Login: Klik tombol Login Verifikator dan masukkan kredensial resmi untuk membuka fitur edit, tambah, dan audit log.
  • Input Single Form: Tambahkan usulan satu per satu dengan melengkapi seluruh atribut wajib pegawai secara mendetail.
  • Batch Form (Tabel Interaktif): Kelola banyak usulan sekaligus dalam bentuk grid/tabel. Anda dapat mengedit, menambah baris, atau mengimpor data dari Excel.
  • Audit Log Aktivitas: Setiap tindakan tambah, ubah, atau hapus data terekam secara otomatis dalam menu Audit Log lengkap dengan timestamp WIB.
Ketentuan Penggunaan Import & Template Excel
Unduh Template Baku: Gunakan selalu tombol Unduh Template Excel di dalam Batch Form untuk memperoleh berkas berformat standar.
Format Bulan (01 - 12): Kolom PERIODE KP pada template diketik berupa 2 digit bulan (misal `08` atau `10`) atau dipilih langsung melalui dropdown agar tidak terkonversi otomatis.
Pencegahan Duplikasi: Sistem akan memverifikasi NIP secara otomatis. Apabila NIP sudah ada di database, sistem akan menampilkan peringatan dan menolak penyimpanan.
